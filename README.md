# Server Discover · 服务器监控台

Server Discover 是一个用于查看 Linux 服务器运行状态的网页工具。登录后，可以查看硬件使用情况、查询进程、登记服务，并管理自己登记的服务。

## 快速启动

在项目目录执行 `./start.sh`（也可执行 `sh start.sh`）。脚本使用当前环境的 `python3`，从 **8789** 开始查找可用端口；如果被占用，就依次尝试后续端口，并在终端显示实际使用的端口。首次运行若提示缺少依赖，执行 `python3 -m pip install -r requirements.txt` 后重试。关闭终端中的服务可按 `Ctrl+C`。

## 页面功能

| 页面 | 可以做什么 |
| --- | --- |
| 运行总览 | 查看 CPU、物理内存、Swap、磁盘和显卡的使用情况；环形图展示内存、磁盘和显存占比 |
| 显卡趋势 | 查看 GPU 利用率、显存使用率的历史曲线和采样明细；有多张显卡时可以切换查看 |
| 服务登记 | 根据 PID 登记运行中的服务，自定义服务名称，查看登记人和运行时间 |
| 进程查询 | 根据 PID、进程名称或启动命令查找进程，并将进程信息填入服务登记表 |

硬件数据约每 **5 分钟**采样一次，页面约每 **30 秒**读取最新数据。历史采样保留 30 天。

## 开始使用

1. 打开监控页面。首次使用时注册账号；已有账号直接登录。用户名支持中文，密码至少 8 个字符。
2. 进入“运行总览”，查看各项资源的最新使用率和采样时间。
3. 进入“显卡趋势”，选择显卡查看最近 24 小时的使用变化。首次启动后需要积累采样点，才能看到完整曲线。
4. 如需登记服务，先在“进程查询”中查找目标进程，点击“填入登记”；也可以在“服务登记”中直接输入 PID。
5. 填写自定义服务名称并提交。名称支持中文。登记完成后，可以在表格中查看状态、开始时间和登记用户。

## 服务登记说明

| 字段 | 含义 |
| --- | --- |
| 服务名称 | 登记时填写的名称，用于识别服务 |
| PID | 服务器上正在运行的进程编号 |
| 进程所属用户 | Linux 系统中运行该进程的用户 |
| 登记用户 | 在监控页面中登记该进程的账号 |
| 开始时间 | 进程在 Linux 系统中的实际启动时间 |
| 停止时间 | 从页面停止时的时间，或系统发现进程已退出的时间 |
| 状态 | 运行中、已停止或已退出 |

只有该记录的登记用户可以在页面上点击“停止”。操作前页面会要求确认；程序会核对 PID 对应的进程，向它发送正常停止信号。如果进程没有及时退出，页面会给出提示。

进程自行结束时，系统会在下一次查看登记表或采样时发现它，因此表中的停止时间可能比实际退出时间稍晚。“登记用户”和“进程所属用户”表示不同身份，不一定是同一个人。

## 指标说明

- **CPU 使用率**：最近一次采样时处理器的使用比例。
- **物理内存使用率**：内存已用空间占总量的比例，同时展示已用、可用和总量。
- **Swap 使用率**：交换空间的使用比例；未启用 Swap 时不显示该卡片。
- **磁盘使用率**：服务器根分区的空间使用比例。
- **GPU 利用率**：显卡计算资源在采样时的使用比例。
- **显存使用率**：已使用显存占显存总量的比例。

如果服务器没有可用的 NVIDIA 显卡信息，页面会显示提示，其他硬件数据仍可查看。刷新页面只是获取已保存的最新数据，不会立即产生新的五分钟采样。
